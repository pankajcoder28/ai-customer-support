# Authentication Requirements Checklist

## 🔐 authenticateToken Middleware - What's Required

### Environment Setup

- [ ] `.env` file contains `JWT_SECRET=your_secret_key`
- [ ] JWT_SECRET is long (32+ characters) and random
- [ ] `.env` is in `.gitignore` (not committed to git)

### User Database Requirements

Every user document must have:

```javascript
{
  _id: ObjectId,           // ✅ Auto-generated by MongoDB
  email: String,           // ✅ From registration/login
  role: String,            // ✅ 'admin' or 'customer'
  tenantId: ObjectId,      // ✅ From auth controller
  isActive: Boolean,       // ✅ Default: true
  username: String,        // ✅ From registration
  avatar: String           // ✅ Optional, default: ""
}
```

### Token Generation (Auth Controller)

```javascript
// This creates the token - no changes needed
const token = jwt.sign(
  { id: user._id, tenantId: user.tenantId },
  config.JWT_SECRET,
  { expiresIn: "7d" },
);
res.cookie("token", token);
```

### Token Payload

Every token contains:

```javascript
{
  id: user._id,           // User database ID
  tenantId: user.tenantId, // Organization ID
  iat: timestamp,         // Issued at time
  exp: timestamp          // Expiration time (7 days)
}
```

### Middleware Attachment

Every protected route must have:

```javascript
// Single user auth
router.post("/send", authenticateToken, sendMessage);

// Admin only
router.get("/admin/tickets", authenticateAdmin, getTenantTickets);
```

### Available in Controllers

After authenticateToken, `req.user` contains:

```javascript
{
  _id: "user_id_123",
  email: "user@example.com",
  role: "customer" or "admin",
  tenantId: "tenant_id_123",
  isActive: true,
  username: "john_doe",
  avatar: "url_or_empty"
}
```

## 🚀 How to Send Tokens

### Method 1: Automatic Cookie (Browser)

```javascript
// Login sets cookie automatically
// Browser sends it with every request automatically
// No special headers needed
fetch("/api/protected"); // ✅ Works with cookie
```

### Method 2: Authorization Header (API/Frontend)

```javascript
// Must include Bearer token in header
fetch("/api/protected", {
  headers: {
    Authorization: `Bearer ${token}`,
  },
});
```

### Method 3: CURL Testing

```bash
# With Bearer header
curl -H "Authorization: Bearer token_value" http://localhost:3000/api/messages

# With Cookie
curl -H "Cookie: token=token_value" http://localhost:3000/api/messages
```

## 📊 Middleware Flow Diagram

```
Request arrives at protected route
         ↓
authenticateToken middleware
         ↓
├─ Extract token from:
│  ├─ req.cookies.token (if exists)
│  └─ Authorization header (if no cookie)
│
├─ No token found?
│  └─ Return 401: "No token provided" ❌
│
├─ Verify JWT signature
│  ├─ Invalid/tampered?
│  │  └─ Return 401: "Invalid token" ❌
│  └─ Expired?
│     └─ Return 401: "Token expired" ❌
│
├─ Decode token: { id, tenantId }
├─ Find user in database
│  ├─ User not found?
│  │  └─ Return 401: "User not found" ❌
│  └─ Account inactive?
│     └─ Return 401: "Account inactive" ❌
│
├─ Attach req.user = { _id, email, role, tenantId, ... }
└─ Continue to route handler ✅

   // Inside controller:
   const userId = req.user._id;
   const tenantId = req.user.tenantId;
```

## 🎯 For Developers Using This System

### In Frontend Components

```javascript
// 1. After login, store token
localStorage.setItem("token", response.token);

// 2. In API calls, include token
const response = await fetch("/api/messages/send", {
  method: "POST",
  headers: {
    Authorization: `Bearer ${localStorage.getItem("token")}`,
    "Content-Type": "application/json",
  },
  body: JSON.stringify({ conversationId, message }),
});

// 3. If 401 error, redirect to login
if (response.status === 401) {
  window.location.href = "/login";
}
```

### In Controllers

```javascript
export const sendMessage = async (req, res) => {
  // req.user is already available from authenticateToken
  const userId = req.user._id; // ✅ Available
  const tenantId = req.user.tenantId; // ✅ Available
  const email = req.user.email; // ✅ Available

  // Use these for database queries
  const message = await Message.create({
    text: req.body.message,
    userId, // ← From req.user
    tenantId, // ← From req.user
    conversationId: req.body.conversationId,
  });
};
```

## 🚨 Common Errors & Fixes

| Error                         | Cause                                | Fix                                                |
| ----------------------------- | ------------------------------------ | -------------------------------------------------- |
| "jwt secret is not available" | JWT_SECRET not in .env               | Add JWT_SECRET to .env                             |
| "No token provided"           | Not sending token                    | Include Authorization header or cookie             |
| "Invalid token"               | Wrong token format                   | Use `Bearer token_value` format                    |
| "Token expired"               | Token older than 7 days              | Login again to get new token                       |
| "req.user is undefined"       | Missing authenticateToken middleware | Add middleware to route                            |
| "User not found"              | Deleted user or wrong ID in token    | Token belongs to non-existent user                 |
| "Forbidden"                   | Not admin for admin route            | Use authenticateToken instead of authenticateAdmin |
